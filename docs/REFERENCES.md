# References

Full bibliographic references for every LITERATURE figure in this documentation. Numbering matches
the source book so a reader can move between the two.

> **How to read a LITERATURE marker.** It means the adjacent figure comes from one of the sources
> below and describes **that study's** result — not a result produced by this system. Nothing in
> this repository has been validated on real patients. See [`../DISCLAIMER.md`](../DISCLAIMER.md).

> **Verification status.** Every entry below was checked against PubMed or the issuing body in
> July 2026 and resolves to a retrievable publication. Entries in an earlier revision of this file
> that could not be verified have been **removed**, along with the claims that rested on them.

## Removed in the July 2026 verification pass

The following entries appeared in an earlier revision as descriptions without bibliographic detail.
None could be traced to a retrievable publication. **Both the entries and the numeric claims that
depended on them have been removed from this documentation.**

| Former ref | Claim it supported | Disposition |
|---|---|---|
| [4] (former) | "ensembles reaching ~88% accuracy in multimodal risk stratification" | **Removed.** Replaced by [4] above, reporting stage-specific AUCs of 0.98 (AD), 0.84 (MCI), 0.78 (SCD) — a more cautious and stage-dependent claim. |
| [14] | "15–20 point accuracy losses on minority populations" | **Removed.** No source located. The 10-point fairness threshold is retained as a *design choice*, argued in ADR-0007 on its own terms. |
| [16] (former) | "AI-EEG ~81% vs ~73% for conventional CSF analysis" | **Removed — could not be verified in any form.** Closest verified figures: [16] above (AUC 0.89, 77% accuracy) and [26] (blood test 91% vs 73% for dementia *specialists*, not CSF). |
| [17] (former) | "ambulatory EEG signal quality degradation of 10–15%" | **Removed.** No source located. Artefact rejection remains a first-class component on general grounds. |
| [18] | "explainable AI improving clinician confidence by ~30%" | **Removed.** No source located. ADR-0006 argues explainability on clinical-adoption grounds instead. |
| [19] | "accuracy falling to ~70% in under-represented populations" | **Removed.** No source located. |
| [25] (former) | "~18% improvement in recall tasks" | **Removed.** Traced to a product with no peer-reviewed evaluation. Replaced by [25] above, which reports a development methodology and a registered feasibility trial with **no effectiveness result**. |

References [5], [6], [13], [22] and [24] were cross-references to descriptive summaries rather than
to publications, and have been retired. Where the underlying point survives it is argued directly
in the relevant ADR.

## Citing this work

Cite the primary sources above rather than this table. Cite this repository only as a **proposed
architecture and methodology** — never as a source of clinical results, because it contains none.
